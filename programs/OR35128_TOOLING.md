## 1. Geometry ที่ถอดได้ (ตรวจสอบแล้ว)

ชิ้นงานคือ **แหวนนอกตลับลูกปืน** — ผนัง 2.883 mm, มีร่องรางลูกปืน (raceway) R3.112 อยู่กลางรูใน
และมุมนอกทั้งสองด้านมีร่องหลบ + ลบมุมตาม DETAIL X

**ค่าที่ยืนยันความถูกต้องของการถอดแบบ** (คำนวณจากค่าอื่นแล้วตรงกับค่าที่พิมพ์ในแบบ):

| ตรวจสอบ | คำนวณได้ | ในแบบ |
|---|---|---|
| วงศูนย์กลางส่วนโค้ง raceway = 30.937 − 2×3.112 | **24.713** | `(24.713)` ✓ |
| ความลึกร่อง R0.304 ใต้ผิว Ø32.855 | **0.1781** | `2× 0.178 ±0.025` ✓ |
| Ø ปลายหน้า + 2×0.33 (C0.33 ที่ 45°) | 32.195 + 0.66 = **32.855** | `Ø32.855` ✓ |
| ระยะแกนของผนัง 4° = 0.779 × tan4° | **0.0545** | 1.326 − 1.272 = 0.054 ✓ |
| C0.235 → 1.579 − 1.326 = 0.253 กับรัศมี 0.2525 | **45°** | `C0.235 ±0.057` ✓ |

### 1.3 GD&T ที่คุมกระบวนการ
- `Ø35.128 ±0.025` (datum B) — circularity **0.03**
- `2×Ø29.362 ±0.024` — circularity **0.05**, runout **0.05 → B**

**runout รู→OD 0.05 คือข้อกำหนดที่กำหนดวิธีจับงาน**: ต้องกลึง OD โดยจับที่รูที่กลึงเสร็จแล้ว (หรือกลับกัน)

## 2. การเลือกรูปทรงเม็ดมีด (Insert Shape Selection)

**สมมติฐานวัสดุ:** 100Cr6 / SUJ2 / AISI 52100 อบอ่อน spheroidised ~190–210 HB (green turning
ก่อนชุบแข็ง) — ถ้าเป็นงานกลึงหลังชุบ (58–62 HRC) ให้เปลี่ยนไปใช้ CBN ตามหมายเหตุท้ายตาราง

### 2.1 ตัวเลขที่บังคับรูปทรงเม็ดมีด

คำนวณความชันจริงของผิวงาน แล้วเทียบกับมุมหลบที่รูปทรงเม็ดมีดให้ได้:

| ผิวงาน | ความชันจากแกน Z | ต้องการ |
|---|---|---|
| ทางออก raceway ที่ชน Ø29.362 | **41.7°** ทั้งสองข้าง | มุมหลบด้านตาม (trailing) > 42° |
| ผนัง 4° ของ DETAIL X | **86°** (4° จากแนวรัศมี) | ต้องใช้มีดเซาะร่อง หรือ lead ≥ 94° |
| ก้นร่องหลบ R0.304 | เว้าเข้า R0.304 | รัศมีปลายมีด **≤ 0.3** |
| ก้น raceway R3.112 | เว้าเข้า R3.112 | รัศมีปลายมีด ≤ 3.1 (ไม่บังคับ) |

จากตารางนี้ **เม็ด 80° (C) และ 55° (D) ใช้เก็บ raceway ไม่ได้** — S16 bar lead 93° + เม็ด 55°
เหลือมุมหลบด้านตามแค่ 32° ซึ่งน้อยกว่า 41.7° → กินเนื้อผนัง raceway
ต้องใช้ **35° (V)** ซึ่งให้ 180−93−35 = **52°** ผ่านฉิว

## 3. กระบวนการ (2 OP)

**Blank:** ท่อไร้ตะเข็บ Ø38.0 × Ø26.0 × ยาว 12.0 (หน้าดิบตั้งไว้ที่ Z+0.4 ใน OP10)

### OP10 — `OR35128_OP10.NC` (จับ OD ดิบ Ø38 ด้วยหัวจับปากแข็ง, ลึก 5 mm)
Z0 = **หน้าชิ้นงานด้านหน้า** = datum แกนของทั้งชิ้น
1. ปาดหน้าถึง Z0
2. หยาบ OD → Ø35.6 เฉพาะช่วงที่โผล่พ้นปากจับ (Z0 → −6.5)
3. คว้านหยาบ Ø29.10 ทะลุ
4. หยาบ raceway 3 พาส (ส่วนโค้ง R2.620 / R2.790 / R2.950 ร่วมศูนย์กับของจริง)
5. คว้านละเอียด Ø29.362 + **raceway R3.112** + C0.305 ด้านหน้า

### OP20 — `OR35128_OP20.NC` (expanding mandrel จับรู Ø29.362 ที่กลึงเสร็จ)
Z0 = **หน้าชิ้นงานด้านหลัง** (ที่จะปาดใหม่), หน้าที่นั่งฟิกซ์เจอร์อยู่ที่ Z−11.125
1. ปาดหน้าหลังให้ได้ความกว้าง 11.125
2. หยาบ OD → Ø35.6 เต็มความยาว
3. หยาบโซน DETAIL X ทั้งสองด้าน → Ø33.3 (T01 ขวา / T07 ซ้าย)
4. **กลึงละเอียด OD Ø35.128 เต็มความยาวในพาสเดียว** ← เงื่อนไข circularity 0.03 + runout
5. ขึ้นรูป DETAIL X ด้านใกล้ (T03) และด้านไกล (T06) อย่างละ semi + finish
6. ลบมุมปากรู C0.305 ด้านหลัง (T08)

### ข้อกำหนดฟิกซ์เจอร์ OP20 (สำคัญ — ถ้าไม่ทำตามนี้จะชน)
- expanding mandrel **2 แหวนจับ** ที่ Ø29.362 กว้างอย่างละ ~3 mm หลบ raceway ตรงกลาง
- แหวนจับด้าน Z0 **ร่นเข้าไป 1.0 mm** เพื่อให้ T08 ลบมุมปากรูได้
- หน้ารองรับ (face stop) **Ø30.0 max** — ต้องเล็กกว่า Ø32.195 เพื่อเปิดทางให้ T06 ขึ้นรูปมุมด้านไกล
- ตัวเรือน mandrel ที่ยื่นพ้น Z−11.125 ต้อง **ไม่เกิน Ø31.0** ไปอีก 3 mm

## 5. แก้ไขจากการรันซิม (1 ส.ค. 2026)

**อาการ:** ปาดหน้า Z0 แล้วยังเหลือวงแหวนเนื้อยื่นพ้นหน้าออกมา ~1.39 mm ที่ Ø35.47 (≈ระดับกลึงหยาบ OD)

**สาเหตุ:** ปาดหน้าเดิมเป็นระยะตายตัว 2 พาส (Z0.24 → Z0) คิดจากสมมติฐานว่า blank ยาว 12.0
เหลือเผื่อปาดแค่ 0.475 พอ stock จริงยาวกว่านั้น มีดจึงลอดใต้เนื้อส่วนเกินไปเฉย ๆ
ส่วนมีดกลึงหยาบ OD (เริ่มที่ Z+2) ก็ไปกลึงข้างเนื้อส่วนเกินนั้นเป็น Ø35.6 ทิ้งค้างไว้

**ครั้งแรกแก้ผิดทาง:** เขียนเป็นลูป macro (`#101` + `WHILE/DO1`) เพราะเห็นว่า `GMF46_1.NC`
ในโฟลเดอร์นี้ใช้ macro ได้ แต่รันซิมแล้วเนื้อยังอยู่เหมือนเดิม — **ซิมไม่ได้รันบล็อก macro**
(ยืนยันจาก DRO: `T808 N214` ตรงกับบรรทัดที่ 214 ของไฟล์ที่แก้แล้ว คือรันจนจบจริง)

**แก้จริง:** เปลี่ยนเป็น **บล็อกปาดหน้าตรง ๆ ไม่ใช้ macro** ใน **ทั้งสองโปรแกรม**
ไล่จากเหนือหน้าดิบลงมาถึง Z0 ทีละ ≤0.25 แล้วปิดท้ายด้วยพาส finish 0.10

| โปรแกรม | พาสปาดหน้า (Z) | X เริ่ม → จบ |
|---|---|---|
| OP10 | **8.0 → 0** รวม 23 พาส (หยาบ 0.5, ละเอียด 0.25, ปิดท้าย 0.10) | X46 → X25 |
| OP20 | **8.0 → 0** รวม 23 พาส (เหมือนกัน) | X46 → X28.5 |

พาสช่วง Z8→Z2 อยู่ใน **บล็อกที่ทำเครื่องหมาย OPTIONAL ไว้** — ลบทิ้งได้เมื่อยืนยันความยาว
blank แล้ว (ไม่งั้นเสียเวลากลึงลมประมาณ 26 พาสต่อชิ้นบนเครื่องจริง)

> เลข N ท้ายโปรแกรมเปลี่ยนไปแล้ว (OP10 = 204 บรรทัด, OP20 = 280 บรรทัด) อย่าเทียบกับซิมรอบก่อน

### วิธีเช็คว่าสต็อกในซิมเป็นอะไรกันแน่

**ทางที่เร็วที่สุด** — เปิดหน้าตั้งค่าสต็อกของซิมเอง (มักอยู่ที่ Setup / Stock / Blank / Workpiece)
ดู 4 ค่า: **OD, ID, Length, ตำแหน่งหน้าเทียบกับ Z0** แล้วบอกผมมา

**ถ้าหาไม่เจอ** — รัน `OR35128_STOCKCHECK.NC` (โปรแกรมนี้ **ไม่กลึงอะไรเลย** มีแต่ rapid + M00)
- STOP 1–8 ไล่ปลายมีดออกจาก Z0 ไป Z12 → จุดแรกที่ปลายมีดพ้นหน้าสต็อก = ระยะที่หน้าดิบยื่นพ้น Z0
- STOP 9–15 ไล่ปลายมีดลงมาจาก Ø60 ถึง Ø36 → จุดสุดท้ายที่ยังพ้นเนื้อ = OD ดิบ

**ถ้ารัน OP20 ใหม่แล้วเนื้อหมดเกลี้ยง** แปลว่า blank ยื่นไม่เกิน 8 mm — เรื่องจบ
**ถ้ายังเหลือ** แปลว่าเป็นงานป้อนบาร์ ต้องเปลี่ยนโครงสร้างเป็น ปาดหน้า → กลึงครบ → **ตัดชิ้น (part-off)**
ซึ่งต้องเพิ่มมีดตัด (เช่น เม็ดตัดกว้าง 2.5–3.0, ก้าน 26 mm) และแก้ลำดับงานใหม่ทั้งหมด

> ⚠️ ชุด OD roughing (`OP10-2`, `OP20-2`) ยังคิดบน blank **Ø38** อยู่ ถ้า OD ดิบโตกว่านั้นมาก
> การ rapid ไป X36.8 แล้วป้อน −Z จะกลายเป็นการกินลึกหลายมิลในพาสเดียว ต้องเพิ่มพาสหยาบก่อนใช้จริง

## 6. หมายเหตุที่ต้องตัดสินใจก่อนใช้งานจริง

1. **โปรแกรมนี้กลึงตามขนาดในแบบ (finish-turn)** ถ้าแหวนต้องผ่านการชุบแข็งแล้วเจียร ให้เผื่อ
   ระยะเจียรเอง — ปกติ 0.20–0.30 ที่ OD/รู/raceway และ 0.15 ที่หน้า — โดยแก้ที่ค่า X/Z ในบล็อก
   finish contour (เขียนไว้เป็นตารางจุดชัดเจนแล้วในโปรแกรม) ผิว DETAIL X และ C0.305 ไม่ต้องเผื่อ
   เพราะไม่ได้เจียร
2. `BREAK CORNER 0.127 MAX / NO BURR` ที่ขอบ raceway — ปลายมีด R0.2 จะทิ้งรัศมีราว 0.2
   ซึ่งเกิน 0.127 ให้ไปทำที่ขั้นตอน deburr/เจียร หรือเปลี่ยน T05 เป็น R0.1
3. แหวนบาง (ผนัง 2.88) — แรงจับเป็นตัวทำให้ circularity 0.03 หลุด ให้จับด้วยแรงต่ำสุดที่ยังไม่ลื่น
   และวัดกลมหลังคลายออกจากหัวจับ
4. G41/G42 ที่ใช้ในโปรแกรมเป็นแบบป้อมมีดหลัง (rear turret) — **ตรวจทิศชดเชยกับเครื่องจริงก่อน**
   และตั้งค่า nose R / tip code ให้ตรงทุกตัว โดยเฉพาะมีดซ้าย T06/T07
5. ยังไม่ได้ตรวจการชนของด้ามมีดกับหัวจับ/ฟิกซ์เจอร์ — **ต้องรัน dry run ก่อน**
